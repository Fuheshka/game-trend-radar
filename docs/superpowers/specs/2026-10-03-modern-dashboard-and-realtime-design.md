## 1. Концепция и избавление от «нейрослопа»

### Главные проблемы старой версии:
1. **Вертикальный монолит:** все элементы (тикер, метрики, радар, фильтры, карточки, каталог) выстроены в одну длинную страницу. Пользователь тонет в скролле.
2. **AI-Slop эстетика:** фиолетовые и лавандовые неоновые свечения (`--border-subtle: rgba(203, 166, 247, 0.18)`), крупные пустые карточки, декоративные тени, размывающие границы.
3. **Имитация Real-Time:** локальный таймер `setInterval` вместо реального серверного стриминга.

### Принципы редизайна 2.0:
1. **Тьма как подложка, а не декорация:** глубокие графитовые уровни (`#08090a` холст -> `#0f1011` карточки -> `#161718` приподнятые панели).
2. **Волосковые границы вместо теней (Hairline Borders):** строгие границы `1px solid #23252a` и легкие внутренние блики создают тактильную четкость инструментов уровня Linear и Raycast.
3. **Строгая типографика и Tabular Nums:** шрифт Inter с отрицательным трекингом (`-0.022em` для заголовков), JetBrains Mono с `tabular-nums` для цифр онлайна (никаких микро-дерганий при обновлении).
4. **Единственный хроматический акцент:** кислотно-лаймовая кнопка запуска сканирования (`#e4f222`) и аккуратные семантические LED-индикаторы статусов (`#27a644` зеленый, `#f59e0b` янтарный, `#eb5757` красный). Все остальные элементы нейтральны.
5. **Плотность данных (SteamDB):** табличное представление каталога с 50+ строками на экран, спарклайнами трендов и быстрой фильтрацией (`Ctrl+K`).
6. **Честный Real-Time через SSE:** нативный протокол Server-Sent Events без лишних npm-зависимостей транслирует этапы сбора данных прямо в интерфейс.

## 3. Архитектура рабочих пространств (Workspaces)

Интерфейс делится на 4 изолированных экрана с мгновенным переключением через сегментированные табы (горячие клавиши `1`, `2`, `3`, `4`):

### 1. Фиксированная плавающая шапка (Header & Status Strip)
- **Логотип и версия:** `Game Trend Radar` + моноширинная плашка `v2.0`.
- **Живой LED-индикатор SSE:** зелёный пульсирующий диод при активном соединении с бэкендом.
- **Селектор снимков:** аккуратный выпадающий список дат из истории `data/snapshots/`.
- **Главный CTA сканирования:** кислотно-лаймовая кнопка `⚡ Запустить сканирование` с отображением реального статуса фазы.
- **Компактная полоса KPI (высота 36px):** 
  `Всего игр: 473` | `Суммарный CCU: 1.42M (+4.2%)` | `Арбитражных ниш: 14` | `Топ дня: Steal An Egg (+180%)` | `Обновлено: 5 мин назад`

### 2. Вкладка 1: 🛰️ Обзор и Радар (Strategic Radar & Blueprints)
- Двухколоночный сплит-экран (высокая информационная плотность без скролла):
  - **Слева (42%):** Компактный паутинный радар (Spider Radar) и круговая диаграмма долей CCU. Клик по лепестку архетипа мгновенно фокусирует вердикт справа.
  - **Справа (58%):** Карточки вердиктов по выбранному архетипу (Opportunity Score, Green/Yellow/Red статус, Core Loop Blueprint, монетизация и кнопка генерации GDD-промпта).

### 3. Вкладка 2: 📈 Лидеры роста и тренды (Market Movers & Social Velocity)
- Скринер аномалий рынка:
  - **Топ-10 суточных лидеров роста:** игры с максимальной дельтой онлайна за 24 часа со спарклайнами динамики.
  - **Вирусные сигналы YouTube Shorts:** карточки мемов с коэффициентом виральности (`viralMultiplier`) до того, как они выходят в чарты.
  - **Новые проекты (< 14 дней):** взрывные новинки Roblox и веб-платформ.

### 4. Вкладка 3: 🎮 Каталог игр (SteamDB Data Grid)
- Плотная таблица высокой емкости (50+ строк на экран):
  - Колонки: `# Ранг`, `Платформа`, `Название игры`, `Архетип`, `Онлайн CCU`, `7d Спарклайн-тренд`, `Opportunity Score`, `Лайки %`, `Действия`.
  - Быстрый поиск по названию (`Ctrl+K`), фильтрация по платформам через чипсы.
  - Переключатель «Таблица (плотно) / Сетка карточек (визуально)».

### 5. Вкладка 4: ⚡ Матрица арбитража ниш (Cross-Platform Arbitrage)
- Изолированное рабочее пространство со сравнением каталогов Roblox и Яндекс Игр.
- Карточки готовых возможностей клонирования: процент схожести, инвестиционный питч, рекомендуемое название и теги для РФ рынка.

### 6. Унифицированный Slide-Over инспектор (Detail Drawer)
- Выдвигается справа при клике на любую строку таблицы или карточку.
- Показывает разбор геймплея, графики онлайна, прямые ссылки на витрины и кнопку вызова `PromptGeneratorModal`.

## 4. Архитектура Real-Time на Server-Sent Events (SSE)

```
[Бэкенд: src/server.ts]
   │  
   ├─► GET /api/events (SSE Stream text/event-stream)
   │     │
   │     ├─► event: connected (clientId)
   │     ├─► event: scan:started (timestamp)
   │     ├─► event: scan:progress { source: 'roblox', count: 120, pct: 25 }
   │     ├─► event: scan:progress { source: 'yandex', count: 240, pct: 55 }
   │     ├─► event: scan:progress { source: 'poki', count: 310, pct: 75 }
   │     ├─► event: scan:progress { source: 'youtube', count: 473, pct: 90 }
   │     ├─► event: scan:completed { snapshotId: 'snapshot-2026-10-03' }
   │     └─► event: snapshot:updated (автообновление данных во всех вкладках)
   │
[Клиент: web/src/services/liveEventService.ts]
   │
   └─► EventSource('/api/events')
         ├─► Обновляет LED статус-бар
         ├─► Отображает реальный ход парсинга
         └─► Реактивно подтягивает свежие данные без перезагрузки страницы
```

## 5. План развертывания на сервере (`fuheshka.qd.je`)

1. **Серверный процесс:** Node.js HTTP сервер на порту 4200 под управлением PM2 (`pm2 start dist/server.js --name radar`).
2. **Reverse Proxy:** Nginx или Caddy с авто-сертификатом Let's Encrypt для домена `fuheshka.qd.je`.
3. **Настройка SSE стриминга в Nginx:**
   ```nginx
   location /api/events {
       proxy_pass http://127.0.0.1:4200;
       proxy_http_version 1.1;
       proxy_set_header Connection '';
       proxy_buffering off;
       proxy_cache off;
       chunked_transfer_encoding off;
   }
   ```
4. **Фоновый сбор:** ежедневный запуск полного сканирования по cron в 03:00 UTC с сохранением снимка и уведомлением всех активных клиентов по SSE.
